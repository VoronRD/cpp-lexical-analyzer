# C++ Lexical Analyzer

Модель лексического анализатора компилятора, реализованная на C++ с использованием Windows Forms.

Проект разработан в рамках курсовой работы по дисциплине «Модуль: Информатика». В основе анализатора лежит детерминированный конечный автомат, построенный для обработки конструкций языка C++.

## Возможности

- лексический анализ исходного текста;
- обработка лексем с использованием конечного автомата;
- использование таблицы переходов между состояниями;
- формирование дескрипторного кода;
- формирование псевдокода;
- визуальное представление результатов анализа;
- обработка конструкции `for` и символьного массива в соответствии с вариантом задания.

## Теоретическая часть

В рамках проекта разработаны:

- детерминированный конечный автомат;
- таблица переходов;
- регулярная грамматика, построенная по конечному автомату;
- контекстно-свободная грамматика;
- блок-схемы алгоритмов;
- описание алгоритмов;
- анализ сложности;
- тестирование программного обеспечения.

## Технологии

- **C++**
- **Windows Forms**
- **Visual Studio**
- детерминированные конечные автоматы
- формальные грамматики
